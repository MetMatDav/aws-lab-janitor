# An approval that nobody answered: 2026-11-14

The approval request of run `20261111T203848Z-138c` was never opened. It was
left alone on purpose, to see what the janitor does when the window closes.
All times are UTC.

| Time | What |
| ---- | ---- |
| 11-11 20:38:47 | Run started by hand with `{"dryRun": false, "minAgeDays": 7}`; one candidate, a decoy dashboard |
| 11-11 20:39:07 | Approval requested; the record expires at 11-14 20:09:07, 71 h 30 min later |
| 11-11 20:39:27 | A reminder started by hand stamped `remindedAt` and sent its email |
| 11-14 20:39:05 | The approval task timed out after 72 hours: `RecordExpired`, `MirrorExpired`, `NotifyExpired`, `Expired` |
| 11-14 20:39:08 | Execution `SUCCEEDED` |

What was checked afterwards:

- The approval record reads `EXPIRED`, closed by the state machine at 20:39:05.
- The mirror item under the run has the event `EXPIRED`, written by
  `statemachine`.
- The reports topic published one message in that hour and delivered it: the
  email that says the approval expired and nothing was deleted.
- The executor was not invoked. No alarm changed state.

The record expired half an hour before the task did, as designed: in those
thirty minutes the link would have answered `410` while the execution was
still waiting, so that a decision cannot arrive in the last seconds and race
the timeout. Nobody opened the link, so that answer was not seen.

The decoy had been deleted by hand two days earlier. Had the request been
approved at the last minute, the executor would have found nothing to delete.
